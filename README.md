# Hill Rivals — бесконечные гонки

## Онлайн-мультиплеер

Игра: https://mirea-racing.sayaka.ru

Главный экран — единое онлайн-лобби: компьютер показывает четыре карточки гонщиков сеткой 2×2, телефон — одного гонщика. При входе автоматически открывается личная комната; список комнат и отдельное создание комнаты не нужны. Код из пяти латинских букв можно скопировать и отправить друзьям, а в нижнем поле можно ввести код чужой комнаты для перехода. В одной комнате до 8 гонщиков. Четыре участника на одном компьютере управляют машинами с WASD, стрелок, мыши и IJKL; четвёртый игрок использует I/L для газа и J/K для тормоза. Каждый компьютер считается одной командой готовности. Телефон подключается как один гонщик. Отсчёт **3 секунды** начинается только после готовности всех команд в комнате. Можно отменить готовность. Новый посетитель или смена персонажа во время отсчёта возвращает комнату к ожиданию; после готовности всех запускается новый полный отсчёт. Ведущий выбирает трассу и общую машину; персонажа и способность можно менять до старта.

Физику своей машины, топливо и способности рассчитывает устройство игрока с шагом 120 Гц, сразу по нажатию кнопок. Оно отправляет положение и состояние машины через WebSocket примерно 30 раз в секунду. Сервер проверяет формат, номер гонки, порядок пакетов и допустимость перемещения, передаёт состояния остальным игрокам, рассчитывает общие бонусы и победителя. Все видят одну трассу с одним сидом. WASD или стрелки — газ/тормоз, E или пробел — способность. На телефонах доступны экранные кнопки. Камера следует за своей машиной; отставание рассчитывается одинаково для всех на сервере. Во время гонки новые посетители наблюдают; после завершения участвуют в следующем старте. Внизу видны количество посетителей, активных гонщиков и готовых участников. В комнате до 8 участников, на сервере до 64 одновременных подключений.

Отключившийся гонщик выбывает. Зависшие команды управления сбрасываются через 1,5 секунды. После потери связи клиент переподключается автоматически. После обновления серверной версии открытые страницы перезагружаются автоматически.

Ведущий управляет настройками комнаты; физика каждой машины остаётся у её владельца. Браузер непрерывно считает свою машину и её столкновения с землёй; входящие снимки не меняют её координаты. Мосты под своей машиной рассчитываются локально, чтобы сетевые пакеты не меняли поверхность под колёсами. Другие машины и падающие бонусы рисуются между серверными снимками; бонусы имеют постоянные ID, поэтому исчезновение одного не меняет траекторию остальных. При коротком разрыве связи чужие машины продолжают движение не более 150 мс, затем замирают до новых данных; собственная машина продолжает локальное движение. Подбор общих бонусов подтверждает сервер, награды применяются локально ровно один раз. Если от клиента нет координат пять секунд, сервер исключает его из гонки. Время анимаций не сбрасывается каждым сетевым пакетом. Рисованные деревья и фон масштабируются со сглаживанием, а уменьшенные текстуры переиспользуются из памяти.

`npm run test:network` проверяет две мобильные сессии с задержками WebSocket 45–165 мс и остановкой ответов на 1,1 секунды: настоящее касание газа ускоряет машину без ответа сервера, локальная физика не замирает, координаты отправляются другим игрокам, ящики двигаются между пакетами. Требуется Chromium из `npx playwright install chromium`.

Режимы переключаются в одной странице через View Transitions с запасной CSS-анимацией, без новой загрузки документа и скриптов. Настройки обычной игры сохраняются при переключении. В меню — прямая дорога, пустая машина и медленно движущиеся облака.

Локальные комнаты обнаруживаются по общему внешнему IPv4 или IPv6-префиксу /64, аналогично PairDrop. Это подсказка: VPN, CGNAT и изоляция клиентов Wi-Fi могут дать неточный список или заблокировать прямое соединение. WebRTC пробует локальные кандидаты без внешнего STUN/TURN; остальные соединения работают через WebSocket. Игра сравнивает задержку прямого канала с полным маршрутом игрок–сервер–игрок–сервер–игрок, выбирает лучший устойчивый путь и возвращается к серверу при отсутствии прямых пакетов 300 мс. Состояния машин идут напрямую 30 Гц; резервная серверная рассылка сокращается до 10 Гц, когда все соседи доступны напрямую. Общие бонусы, проверка координат и результаты остаются на сервере: этот режим пока требует интернета.

Для определения сети nginx должен передавать доверенный адрес клиента через X-Forwarded-For. В конфигурации с SNI-маршрутизатором используется $proxy_protocol_addr, а контейнер включает TRUST_PROXY=1; контейнер доступен только через локальный nginx.

`npm run test:rooms` проверяет списки, коды, ведущего, чат, WebRTC, сохранение настроек и отсутствие перезагрузки режимов в настольном и мобильном браузерах.

### Локальный запуск сервера

Требуется Node.js 24: `npm ci`, затем `npm start`. Откройте http://127.0.0.1:3107 в нескольких вкладках или браузерах. `npm test` проверяет готовность, отсчёт, отключения и физику всех машин. `node test/smoke.mjs` проверяет две настоящие WebSocket-сессии; для проверки опубликованной игры задайте `TEST_URL=https://mirea-racing.sayaka.ru`.

### Развёртывание

Игра работает отдельным непривилегированным Docker-контейнером `hill-rivals`, порт `127.0.0.1:3107`. Конфигурации находятся в `deploy/`. На этом сервере nginx принимает HTTPS через SNI-маршрутизатор и направляет домен в `127.0.0.1:9458` с PROXY protocol. Сертификат Let's Encrypt продлевается через HTTP webroot `/var/www/certbot`.

Служба `hill-rivals-webhook` принимает только подписанные SHA-256 уведомления GitHub для push в `fecatt/hill-rivals:main` и запускает `hill-rivals-update.service`. Секрет хранится вне репозитория: `/etc/hill-rivals/webhook-secret`. Резервный `hill-rivals-update.timer` проверяет main раз в 10 секунд. Коммит собирается в Docker, проходит тесты и проверку физики до замены работающего контейнера; при неудачной проверке HTTP восстанавливается прежний образ. Обновление занимает время сборки и кратко перезапускает комнаты. Изменения в других ветках не публикуются.

Команды на сервере: `systemctl status hill-rivals-webhook hill-rivals-update.timer`, `journalctl -u hill-rivals-update.service`, `docker logs hill-rivals`. Ручное обновление: `systemctl start hill-rivals-update.service`.

## Установка на телефон

Кнопка «Установить» использует системное предложение установки, если браузер его поддерживает; иначе показывает инструкцию для Android и iPhone. Manifest содержит отдельные значки 192/512 и standalone-режим. Service Worker сохраняет игровые файлы для запуска после первой загрузки. Для общей онлайн-комнаты нужен интернет. Статические файлы проверяются через сеть при доступном соединении, поэтому обновления не застревают в офлайн-кеше.

## Режим на одном компьютере

Откройте `dist/index.html` в браузере. Установка и интернет не нужны. Выберите персонажа и способность каждого игрока, затем маршрут и «На старт».

## Управление

- Игрок 1: W/D — газ, S/A — тормоз и задний ход; E — способность.
- Игрок 2: ↑/→ — газ, ↓/← — тормоз и задний ход; правый Shift — способность.
- Игрок 3: ПКМ — газ, ЛКМ — тормоз и задний ход; нажатие колёсика на поле игры — способность.
- Esc — пауза. Звук включается в верхнем меню.

Удержание тормоза останавливает машину, затем включает задний ход. Газ поднимает нос, тормоз опускает его. Особенно осторожно работайте с газом в полёте и при турбо. Колёса имеют независимую подвеску и сцепление. Удар головой о землю вызывает переворот.

## Случайная карта и бесконечный мир

При каждом старте и повторной гонке генерируется новый вариант рельефа, расположения мостов и порядка биомов в Большом путешествии. Все три игрока едут по одной и той же карте заезда. Бонусы и интервалы снегопада случайны независимо от геометрии трассы.

Все семь маршрутов бесконечные: Зелёные холмы, Горы, Луна, Шоссе, Город, Зима и Большое путешествие. Конечного финиша нет. Мосты появляются в холмах и горах как подвесные пролёты, в городе — над каналами; на шоссе мостов нет. Заправки продолжают появляться на любом расстоянии. Видимые участки вычисляются по мере движения, вся трасса в память не загружается.

В Большом путешествии каждый биом занимает около 0,9 км. Пять биомов — холмы, горы, шоссе, город, зима — идут в новом случайном порядке; после полного цикла смена биомов продолжается. Рельеф плавно меняется на границах биомов. У остальных карт выбранный биом сохраняется на всём протяжении.

На Луне гравитация в шесть раз слабее, прыжки дольше. Зимой снегопад начинается периодами со случайными паузами. Деревья на холмах крупные. Настил мостов является поверхностью для колёс; ограждения — декорация.

## Победа, топливо и бонусы

Камера отдаляется при увеличении разрыва, максимум примерно в 2,4 раза. Если машина полностью ушла за левый край расширенного экрана, игрок выбывает. Побеждает последний не выбывший игрок. При гибели всех показываются пройденные дистанции.

Заправки примерно каждые 44 метра полностью восстанавливают топливо. Газ и задний ход расходуют топливо; берегите его на спусках и в воздухе. Бонус падает примерно за 1,5 секунды, после приземления лежит на трассе. Его забирает только первый коснувшийся игрок; бонус исчезает для всех. F — 40 топлива, » — турбо на 5 секунд, ◆ — щит на 12 секунд.

Способность выбирается в гараже:

- Турбо: ускорение 2,8 секунды, перезарядка 11 секунд.
- Прыжок: импульс вверх, перезарядка 8 секунд.
- Щит: защита 4 секунды от одного переворота, перезарядка 14 секунд.

Перезарядка показана под топливом. Способности недоступны во время отсчёта, паузы и после выбывания. Удержание клавиши не активирует способность повторно.

Все семь персонажей взяты из предоставленной папки. Машины и окружение рисуются Canvas.

## Машины, персонажи и анимация подвески

В гараже один общий выбор машины для всех трёх игроков: классический джип, песчаный багги, пикап, ралли, монстр-трак и хот-род. Все игроки используют выбранную модель; отличаются цвет и персонаж. У каждой модели собственные физические характеристики.

Персонажи имеют полную сидячую посадку с ногами и обувью. Егерь и Рэп зеленный отражены, чтобы смотреть вперёд. Голубой переименован в Гейнинзя, Комунистичкий — в Комунинзя.

Визуальная подвеска рисует рычаги и пружинные амортизаторы. Колёса независимо сжимаются на поверхности и вытягиваются в воздухе, кузов слегка покачивается при приземлении. Анимация сглаживается отдельно от физических координат и останавливается на паузе.




## Разные характеристики и турборакета

Масса влияет на ускорение от двигателя, подвески и ракеты, а также на момент инерции. Все видимые оси рассчитываются отдельно. Радиус колеса используется при контакте с землёй, вращении и отрисовке. Жёсткость, демпфирование, ход подвески, сцепление, тяга и предел скорости задаются для каждой машины.

| Модель | Масса | Оси / колёса | Радиусы колёс | Предел скорости без турбо | Ход / жёсткость подвески |
|---|---:|---:|---|---:|---:|
| Джип | 900 кг | 2 / 4 | 18 / 18 | 72 км/ч | 12 / 95 |
| Багги | 580 кг | 2 / 4 | 21 / 21 | 77 км/ч | 20 / 52 |
| Пикап 6×6 | 1600 кг | 3 / 6 | 22 / 22 / 22 | 60 км/ч | 15 / 110 |
| Ралли | 760 кг | 2 / 4 | 16 / 16 | 88 км/ч | 8 / 135 |
| Монстр-трак 8×8 | 2800 кг | 4 / 8 | 28 / 28 / 28 / 28 | 52 км/ч | 24 / 150 |
| Хот-род | 1050 кг | 2 / 4 | 24 сзади / 15 спереди | 101 км/ч | 9 / 145 |
| Турборакета | 980 кг | 2 / 4 | 14 / 14 | 117 км/ч | 10 / 115 |

Радиусы и ход указаны в условных единицах игрового мира. В боковом виде видно по одному колесу каждой оси: у пикапа три, у монстр-трака четыре. Максимальная скорость — предел, достижение которого зависит от поверхности и управления. Турбо повышает предел скорости на 24%.

Турборакета — отдельная общая модель. Держите газ для тяги вперёд и вверх; она работает и в воздухе. Отпускайте газ для снижения, тормозом корректируйте наклон. Способность «Турбо» усиливает ракетный двигатель. Ракета расходует 9 единиц топлива в секунду; без топлива двигатель выключается. Высоко пролетевшая над заправкой ракета не заправляется: станцию нужно пройти у земли. Камера следует по высоте и отдаляется с учётом вертикального разрыва.

Багги легче и быстрее ускоряется, пикап мощнее на подъёмах, ралли имеет жёсткую короткую подвеску, монстр-трак устойчивее и медленнее, хот-род имеет разные передние и задние колёса и сильный двигатель. Результаты разгона действительно отличаются в симуляции.

Проверены семь разных разгонов, количество физических контактов колёс, устойчивость в покое, задний ход каждой модели, расход топлива, взлёт ракеты и вертикальная камера. Шесть обычных моделей прошли километровый участок случайного рельефа с регулировкой газа и тормоза. В браузере проверены выбор и характеристики, запуск и взлёт ракеты.

## Обновление холмов, машин и одиночного режима

В гараже доступны 1, 2 и 3 игрока. Соло — бесконечный заезд на дальность. Управление: W/D — газ, S/A — тормоз, E — способность. Гибель или остановка без топлива завершают заезд. В локальной гонке с друзьями побеждает последний оставшийся.

На Зелёных холмах подробный пиксельный пейзаж, отдельные облака и солнце с едва заметным гербом. Жёлтые лучи плавно затухают и медленно вращаются. Движущиеся облака проходят перед солнцем. Деревья используют прозрачные спрайты, растут рощами на пологих участках; основания скрыты травой и грунтом. Остальные биомы сохраняют прежнее оформление.

Мосты на холмах состоят из настила и низкого ограждения. Под пролётом нет грунта, опор, башен и тросов. Две затухающие формы колебаний реагируют на вес колёс. Контакт колёс учитывает вертикальную скорость полотна. После проезда мост возвращается к обычному провисанию.

Вертикальная камера следует за машинами и вверх, и вниз, с небольшим упреждением по скорости. Впадины не уводят машину за нижний край.

Все семь красных кузовов — отдельные рисованные спрайты car-*.png. Арки привязаны к существующим осям, колёса рисуются позади кузова. У джипа вырезаны внутренние стенки арок. Видимый радиус шин совпадает с физическим. У персонажей видны только голова и верхняя часть туловища; ног и обуви в машинах нет. Пружины и рычаги не рисуются, расчёт подвески сохранён. Базовые параметры массы, двигателя, подвески, колёс и пределов скорости не изменены.

Коробки опускаются на полосатых парашютах, приземляются на трассу и мосты, слегка отскакивают и скользят на крутых склонах. После касания парашют складывается. Топливо, турбо и щит имеют собственные пиктограммы. Коричневая коробка с какашкой пачкает все колёса на 6 секунд: сцепление снижается до 22%, колёса пробуксовывают, видны грязь и брызги. Повторное попадание обновляет таймер. Дополнительного ограничения скорости нет.

Пламя турбо и ракеты анимировано: меняются форма и длина, появляются искры. На паузе анимация останавливается.

Проверены синтаксис JavaScript, одиночный заезд и его завершение, победа в локальном multiplayer, поведение мостов под нагрузкой и без неё, приземление коробок, грязь и восстановление сцепления, движение камеры по 6-километровому участку. Изображения проверены настоящими функциями отрисовки через нативный Canvas; браузерная проверка локальной file:// страницы не подтверждена.


## Мобильный интерфейс и отрисовка

В гонке используется компактная панель топлива, скорости и способности; на телефоне в онлайне показывается только собственный гонщик. Меню выбора режима и установки скрыто на время заезда. Гараж прокручивается, игровые кнопки учитывают безопасные края экрана и работают одновременно несколькими пальцами. В обычном режиме кнопки управляют первым игроком.

Canvas ограничен коэффициентом 1,5 на сенсорных устройствах, 2 на остальных и бюджетом 2,4 млн пикселей. Повторно используются уменьшенные текстуры пейзажа. Панель показателей сохраняет DOM и обновляется 10 раз в секунду, отсчёт комнаты — при смене секунды. Отрисовка ограничена 60 кадрами в секунду в гонке и 15 в меню; в скрытой вкладке она останавливается. Физика по-прежнему работает с шагом 1/120 секунды. Собственная онлайн-машина сразу реагирует на управление через общую физику клиента и сервера, небольшие поправки позиции сглаживаются. Соперники интерполируются с адаптивным буфером 60–140 мс и кратким упреждением при пропуске пакета. После 250 мс без пакетов локальное предсказание останавливается; столкновения, выбывание, бонусы и результат подтверждает сервер. Перед входом в комнату и локальным стартом экран загрузки ждёт загрузки и декодирования всех используемых изображений; при ошибке доступен повтор. Сервис-воркер сохраняет все игровые текстуры, включая атлас окружения.

Проверка мобильного браузера: `npm ci`, `npx playwright install chromium`, `npm run test:mobile`. Тест запускает отдельный сервер и проверяет портретный/альбомный режим, узкий экран, DPR, удержание и отмену сенсорного газа, сохранение элементов HUD, интерполяцию, переход к следующей гонке и управление на компьютере. Можно задать `CHROME_PATH` для установленного Chromium и `TEST_SCREENSHOT_DIR` для снимков интерфейса.


Масштаб расстояния откалиброван по короткому классическому джипу: 112,592 единицы игрового мира соответствуют приблизительно 3,33 м. За ориентир взят Willys MB (https://americangimuseum.org/collections/restored-vehicles/truck-%C2%BC-ton-4x4-willys-mb-jeep-1941-1945/); рисунок стилизованный. Скорость и расстояния используют один коэффициент 33,8114 единицы/м, независимый от масштаба камеры и плотности экрана. Параметры физики, ускорение и места заправок сохранены. На ровной тестовой дороге без турбо за 2 секунды джип проходит около 20,6 м; скорость в этот момент составляет около 66 км/ч. Максимум без турбо — около 72 км/ч, с турбо — около 90 км/ч.


Комнаты создаются с автоматическим названием; ведущий может переименовать комнату после входа. Приглашение содержит код в ссылке `?mode=online&room=ABCDE` и отображается локально в виде QR-кода. Выбранное имя игрока сохраняется на его устройстве и передаётся при последующих подключениях; по умолчанию участники называются «Игрок 1», «Игрок 2» и далее.
