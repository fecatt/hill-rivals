# Hill Rivals

Откройте `dist/index.html` двойным щелчком в браузере. Интернет и установка не нужны. Выберите персонажей каждого из трёх игроков и нажмите «На старт».

Игрок 1: W/D — газ, S/A — тормоз. Игрок 2: ↑/→ — газ, ↓/← — тормоз. Игрок 3: правая кнопка мыши — газ, левая — тормоз. Нажимать мышь нужно на поле игры. Esc — пауза.

Газ поднимает нос машины, тормоз опускает. Подвеска и сцепление рассчитываются отдельно для каждого колеса. Избегайте удара головой о землю. Топливо расходуется быстрее с газом; отпускайте его на спусках и в полёте. Флаги каждые 150 метров полностью заправляют бак. Падающие бонусы: F — топливо, » — турбо на 5 секунд, ◆ — щит на 12 секунд, спасает от одного переворота. Каждый игрок может подобрать один и тот же бонус один раз.

Камера движется за лидером. Машина, полностью ушедшая за левый край экрана, выбывает. Побеждает первый до финиша 900 метров либо последний оставшийся игрок. При гибели всех показываются пройденные дистанции.

Все семь изображений персонажей скопированы из предоставленной пользователем папки. Графика окружения и машин рисуется кодом Canvas. Два варианта трассы. Звук включается кнопкой в верхнем меню.

Проверены программно: движение, заправка, переворот, остановка без топлива, появление и подбор бонусов, выбывание за экраном, финиш. Визуальная проверка браузера и скриншоты не завершены из-за ограничения инструмента управления браузером.
